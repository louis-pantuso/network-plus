# network-plus

Lab notes and Packet Tracer files while I study for CompTIA Network+ (N10-009).

I'm coming from industrial work, using Linux daily, and documenting what I actually build — not a dump of tutorial clones.

## Labs

Writeups live in [`labs/`](labs/). Each note covers:

- What I built
- What I learned
- IPs / commands if it matters

`.pkt` files are included when they're small enough to be useful.

## How to open a .pkt

Install [Cisco Packet Tracer](https://www.netacad.com/) via the free Skills for All / Getting Started course and sign in with that account.
