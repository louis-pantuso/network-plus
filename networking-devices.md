## Networking Devices 
- Router 
    - Takes data from one ip subnet to another 
    - Routers inside of switches are usually refered to asLayer 3 switch

- Switch 
    - A switch operates at level 2 
    - Forwards traffic based on data link addresss (MAC)
- Firewall
    - Filter traddic by port number or application 
        - traditional vs ngfw 
    - encrypt traffic 
        - vpn between sites
        - can act as a layer 3 device/ router 
-  Intrusion Detection System / Intrusion Prevention System
    - Watch network traffic 
    
    - Intrusions 
        - Exploits againsts systems 
    - Detection vs Prevention 
        - Detection, Alarm 
        - Prevention, Stop it before it gets into the network

- Load Balancer 
    - Manages heavy web usage 
    - Distributes the load 
    - Multiple Servers 
    - Larger scale implementations such as server and database farms. 
    - Useful for outages, fast convergence 

- Proxies 
    - sits between the users and the external site 
    - useful for access control, url filtering and content scanning


- Network Attached Storage (NAS)
    - connect to a shared storage device across the netwrok
    - file-level access
- Storage Area Network (SAN) 
    - Looks and feels local 
    - Very efficient 
- Access Point 
    - Used for wireless coms only 
    - Physical to wireless bridge 
    
- Wireless LAN controllers 
    - Centralized management of access points 
    - Performance and Security Monitoring 
    - Proprietary systems
