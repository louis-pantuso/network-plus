Content Delivery Network 
    - Designed to be an effcient means of data transportation 
    - Geographically distributed. 
    - Think of mirrors for a linux download. I chose a mirror closest to me geographically. 

Virtual Private Network
    - connect to remote network on an insecure medium 
    - concentrator / head-end 
    - Many deployment options 

Quality of Service 
    - Traffic shaping, packet shaping 
    - Control data rates, bandwidth usage and set priority to applications 
TTL ( Time To Live ) 
    - How long should data live for? 
    - Not all systems or protocols are self regulating
    - wait till
        1. Hop count 
        2. time 
Routing Loop 
    - Happens on big networks 
    - Easy to cause 
    - TTL is built in to stop this from happening 

IP ( Internet Protocol) 
    - A router decreases TTL by 1
        - at zero, it dies 
    - Each Pass through a router is a hop
    - Loops cause packets to live forever ey
